Una base flexible para YCAM

¿Por qué WordPress?

Existen diferentes formas de crear una web. Algunas soluciones utilizan plantillas muy cerradas, en las que gran parte del diseño y funcionamiento ya viene predeterminado. Esto permite crear una web rápidamente, pero puede limitar las posibilidades de adaptación.

Para YCAM hemos optado por WordPress porque permite construir una web adaptada a la empresa y, al mismo tiempo, incorporar nuevas herramientas y funcionalidades según las necesidades que vayan apareciendo.

01 · Diseño visual

Elementor

Permite diseñar y modificar visualmente gran parte de la web sin tener que programar cada elemento desde cero.

02 · Funciones

Plugins

Permiten añadir funciones concretas a la web sin tener que desarrollar todo desde cero.

03 · Herramientas

Integraciones

WordPress permite incorporar herramientas relacionadas con posicionamiento, analítica, publicidad, contacto y otras necesidades que puedan surgir.

04 · A medida

Desarrollo propio

Cuando una función concreta no existe o no merece la pena incorporar un plugin, también puede desarrollarse de forma personalizada.

Preparada para evolucionar

Una web que puede crecer

La ventaja de esta estructura es que la web no tiene por qué quedar limitada a lo que ofrece la versión inicial. A medida que YCAM lo necesite, pueden incorporarse nuevas herramientas o funcionalidades.

Por ejemplo, en la versión definitiva podría incorporarse una herramienta como Buttonizer para facilitar el contacto directo mediante WhatsApp o teléfono.

Elegir según cada necesidad

Herramientas de pago y alternativas

Algunas herramientas ofrecen funciones avanzadas mediante planes de pago. Antes de incorporarlas, se puede valorar si la misma necesidad puede resolverse mediante herramientas gratuitas o mediante desarrollo personalizado. De esta forma se evitan costes innecesarios y se mantiene la web sencilla de gestionar.

Elementor dispone de funciones adicionales mediante planes de pago, pero no todas las necesidades requieren una herramienta premium. Dependiendo de cada caso, algunas funciones pueden resolverse con herramientas gratuitas o mediante código personalizado.
